# 🔔 FunPayNotifier

**FunPayNotifier** — это легкая утилита для Windows, которая мгновенно присылает системные уведомления на рабочий стол при получении новых сообщений на сайте **FunPay**. 

Программа работает в фоновом режиме с помощью вашего `golden_key`, поэтому вам больше не нужно держать открытой вкладку браузера, чтобы не пропустить важного покупателя или заказ.

---

## ✨ Основные возможности

* **Мгновенные уведомления:** стандартные всплывающие кастомные уведомления о новых сообщениях.
* **Работа без браузера:** приложение само опрашивает серверы FunPay в фоне.
* **Минимальное потребление ресурсов:** программа практически не нагружает систему и тихо работает в трее.
* **Простая настройка:** для запуска нужен только ваш `golden_key`.

---

## 🚀 Установка и запуск

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте последнюю версию программы (`FunPayNotifier.exe`).
2. Поместите файл в любую удобную папку.
3. Запустите программу.
4. Введите ваш **`golden_key`** при первом запуске.

---

## 🔑 Где взять `golden_key`?

1. Откройте сайт [FunPay](https://funpay.com) и войдите в свой аккаунт.
2. Нажмите клавишу **`F12`** (или `Ctrl + Shift + I`), чтобы открыть инструменты разработчика.
3. Перейдите во вкладку **Application** (Приложение) в Chrome/Edge или **Storage** (Хранилище) в Firefox.
4. В левом меню раскройте пункт **Cookies** и выберите `https://funpay.com`.
5. Найдите в списке строчку **`golden_key`** и скопируйте её значение (столбец *Value*).

> ⚠️ **Важно:** Никому не передавайте свой `golden_key`! С его помощью можно получить полный доступ к вашему аккаунту FunPay.

---

## 🛡️ Безопасность и открытость

* Программа использует `golden_key` исключительно для авторизации запросов к FunPay на вашем компьютере.
* Данные не передаются на сторонние серверы.
* Проект распространяется под лицензией **AGPL-3.0**.
